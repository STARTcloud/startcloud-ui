# Requests from other repos for startcloud-ui to implement

This file is never a tracker: every entry is a request from another repository or an answer owed to one, it stays until done and is then removed, and the file's goal is zero lines. Every contract citation is `startcloud-ui/docs/guides/<file>`; every code citation is a path in the repository it names.

| From | Request | Contract |
| ---- | ------- | -------- |
| BoxVault | Every row of the hierarchy now carries `is_public`, `guest_access` and `published`, the same three words the version, release and patch pickers already draw: box providers, box architectures, box files, ISO files and download files. Each is born private, closed to guests and unpublished unless the create or upload says otherwise, never wider than the row above it, a wider word refused 422 with `pointer` on the word and `params.enum: 'false'`. The pickers and the bulk actions (`make_public`, `make_private`, `publish`, `unpublish`, `allow_guests`, `deny_guests`) reach these levels too: `POST …/provider/bulk`, `POST …/architecture/bulk`, `POST …/iso/:name/version/:v/architecture/bulk` (names are architectures) and `POST …/patch/:patch/file/bulk` (names are keys or file names) all take them, a row wider than its parent answered `forbidden` in `errors`. Single writes: `PUT …/provider/:name` and `PUT …/architecture/:name` take the words beside their other members; `PUT …/patch/:patch/file/:key` likewise; a box file's words go to the new `PUT …/architecture/:arch/file` and an ISO file's to the new `PUT …/iso/:name/version/:v/architecture/:arch/file`, both a JSON body of the three words only. Every upload route takes the words as query members `?is_public=true&guest_access=true&published=true`; on the drop routes (`…/download/file/upload`, `…/download/:name/file/upload`, `…/pending/:id/place`) they apply to every row the drop creates, product included. Readers filter every level by the caller's reach, so a provider, architecture or file the caller cannot reach is simply absent from the tree, and a file the viewer cannot reach answers 404 on info, link and download. | `BoxVault/backend/app/controllers/file/edit.js`, `BoxVault/backend/app/controllers/iso/file/edit.js`, `BoxVault/backend/app/rules/bulkLeaf.json`, `BoxVault/backend/app/rules/boxFile.json`, `BoxVault/backend/app/rules/isoFile.json` |
