## 2. Decisions (a number is the identity draft's, a–g the sidebar's, h–m branding and build; §5 lists what is still open)

Shape:

- The auth server serves no HTML: every page is a page of the shared build served at `/`, role `auth-server`, first auth token `cookie`, a fourth session provider `createCookieSession`; restore caches the profile in localStorage under `account`, `load()` confirms through `GET /api/user`.
- GET on a shared path is the SPA page, POST is the server action; protocol redirects stay top-level navigations; a POST answers `{ next }` or `application/problem+json` with `code` (and `wait_seconds` when throttled) on `Accept: application/json`.
- Onboarding gate moves from the MVC interceptor to `403 onboarding_required` with `next` on `/api/*`; the authorize filter is unchanged; one state call `GET /api/auth/onboarding`.
- Feature tokens, the fourteen of decision y and the identity contract's status table: `local-accounts`, `tfa`, `onboarding`, `interstitials`, `policies`, `org-console`, `invitations`, `integrations`, `inbox`, `admin`, `notifications`, `health`, `events`, `footer` (12: `interstitials` over `oauth-interstitials`); the config editor is the shared editor, so no `issuer-config` token; passkeys, the magic link and the providers are rows of `GET /api/auth/methods`, not tokens, and the profile's Sessions, Favorites and Service accounts draw when the adapter carries their calls, so none of those is a token either.
- `/api/admin/**` gains the session-plus-CSRF principal beside Bearer.
- The fifty-odd XHR routes move under `/api/user/*`, JSON snake_case, problem bodies; browser paths unchanged (14, one release, no aliases).
- `POST /api/user/step-up { password | code }` arms a five-minute window and replaces `stepupPassword` and `stepupCode`; a sensitive call outside the window answers `403 step_up_required` and the dialog arms it and retries; no DELETE carries a body.
- Password minimum 15 from `/api/rules`; the confirmation field is the page's `equals` rule (group 2).
- The navbar is the shared chrome branded per site (`help_url` → `links.docs`, `support_email` → `links.contact`).
